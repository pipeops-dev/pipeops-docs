# Mintlify Migration Status

**Last updated:** 2026-08-28  
**Scope:** Docusaurus → Mintlify clean cutover

## Status legend

- **completed** — migrated and verified.
- **blocked** — cannot complete with the current repository/tooling; needs an external decision or dependency.
- **skipped** — intentionally excluded because it is Docusaurus demo/boilerplate or outside the product docs scope.
- **needs-setup** — supported by Mintlify but requires dashboard, domain, secret, or third-party configuration.
- **limitation** — no direct native equivalent identified; retained as a documented follow-up.
